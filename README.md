# discordbot.js — Documentation

This is the documentation site for [discordbot.js](https://github.com/shir0sys/discordbot.js), a Discord API v10 wrapper for Node.js built on native `fetch`/`WebSocket`/`crypto`/`dgram` (the one runtime dependency, `opusscript`, is used only for voice).

Built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/), with the API reference generated by [starlight-typedoc](https://starlight-typedoc.vercel.app/) directly from `discordbot.js`'s TypeScript source.

## What's here

- `src/content/docs/guides/` — hand-written guides (getting started, slash commands, components, interactions, sharding, OAuth2, voice).
- `src/content/docs/index.mdx` — the homepage.
- Everything under the "API Reference" section of the sidebar is generated at build time by `starlight-typedoc` from `discordbot.js`'s source — not maintained by hand.
- `src/styles/custom.css` — Discord's color palette applied to Starlight's theme tokens.

## Building locally

```bash
npm install
npm run dev     # clones/updates discordbot.js into vendor/, then starts the dev server
npm run build   # production build into dist/
npm run preview # serves the dist/ build locally
```

Every build pulls the latest `main` branch of `discordbot.js` into `vendor/` (gitignored) — this repo carries no copy of the library's source itself, only the guides and the Starlight/TypeDoc configuration pointing at it.

## Updating guides

Guides live in `src/content/docs/guides/*.md` with Starlight frontmatter (`title`, `description`). Add a new guide by creating the file there and adding it to the sidebar in `astro.config.mjs`.

## Updating the logo/favicon

Source images live in `media/` (`logo.png`, `favicon.png`). The build reads them from `src/assets/logo.png` and `public/favicon.png` — update those copies (or re-run the copy) when replacing them.

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and publishes `dist/` to GitHub Pages.
